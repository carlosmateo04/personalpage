Posting service

One connection covers TikTok, Instagram, YouTube and Facebook. Clipper sends the clip and its text to Upload-Post, which posts it to the accounts you connected there.

  1. Create an account at upload-post.com.
  2. In Upload-Post, create a profile and connect your four social accounts to it.
  3. Create an API key there and paste it below.

The key is kept on this computer (in Windows Credential Manager) and is never shown again or sent anywhere except the posting service.

Automatic review

Before a clip is made, Claude looks at frames from it and reads what is said. It drops clips that are not pure gameplay (a streamer on screen or talking, cutscenes, menus), picks the section and writes the title, the headline and the description, so nothing has to be edited by hand. Without a key, Clipper writes the titles by its own simpler rules.

  1. Create an account at console.anthropic.com and add a few dollars of credit.
  2. Create an API key there and paste it below.
